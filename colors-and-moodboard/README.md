# Colors, Typography, Moodboards and Replicating Designs

These projects were all about praacticing my design skills by identifying colors and typography, creating moodboards, and recreating existing UI designs in Figma.

For the Timer, I focused on using basic shapes like half-circles and gradients to build a custom visual.

The Watches challenge was more about using Figma's features like symbols, variants, overlays, and masks to accurately copy the watch interfaces.

With the Flight screen, it was similar, emphasizing symbols, variants, overlays, and masking for those location icons.  

The Spotify challenge involved using linear gradients for the background, working with Apple's design system for the header, and again, mastering symbols and variants for the song listings.  

Finally, the Bitcoin Dashboard pushed me to use symbols and variants on a larger scale, along with overlays, masking, and linear gradients.  Across all of them, keeping my layers named and organized was key!  It was great practice for getting really comfortable with Figma's core tools and paying attention to detail.

### Key Skills I practiced:

* Figma Fundamentals: Mastering basic shapes, gradients, and layer organization.
* Component Libraries (Symbols & Variants): Efficiently creating and managing reusable UI elements.
* Advanced Figma Techniques: Using overlays and masks for more complex UI elements.
* Attention to Detail: Accurately replicating existing designs.
* Working with Design Systems (Apple): Understanding and implementing established UI patterns.
* Basically, I sharpened my Figma skills by recreating a variety of UI designs, focusing on using its key features effectively and paying close attention to detail.
