# Building an Interface for a Second-hand Electronics Shop
I basically built the whole user interface for a second-hand electronics app.
First, I set the look and feel with a style guide – moodboard, colors, fonts.

Then, I created a design system with reusable components like buttons and product cards, making sure they had different states.

After that, I designed the main app screens based on some wireframes, bringing them to life visually. To show how it would actually work, I added some animations in Figma.

Finally, I did a quick test with people to see if the vibe I was going for actually came across.  

Learned a ton about design systems, UI, prototyping, and about user feedback!"

Key Skills:

* Visual design and branding (style guide)
* Building design systems for efficiency and consistency
* Translating wireframes into polished UI
* Prototyping with animations in Figma
* Getting initial user feedback on design direction
